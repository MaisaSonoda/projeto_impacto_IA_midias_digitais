Olá! Nosso projeto visa em analisar um dataset que documenta o impacto da IA nas mídias digitais.

Buscamos mesclar os conceitos de análise e ciência de dados, trazendo uma visão buscando compreender os fatos que os dados trazem, bem como fazer previsões com o uso de machine learning.
Nossa proposta foi fazer grande uso da visualização de dados de forma que ela seja um bom suporte para apresentarmos o projeto aos membros da FEA.dev. Além disso, trouxemos a mescla de SQL e Python para fazer algumas análises. Além disso, fizemos análises de correlação (e estatísticas descritivas também, de modo geral) e por fim, testamos variados tipos de modelos de machine learning (Random Forest, Decision Tree e outros) para testarmos entendermos o que melhor se adequa ao projeto proposto, e como eles funcionam.

Espero que goste!
